# 💳 Credit Card Financial Dashboard

An end-to-end Power BI project that analyzes weekly credit card transactions and customer data using MySQL as the data source. The project includes data import, transformation, DAX calculations, and interactive dashboards for business insights.

---

## 🚀 Project Overview

This project demonstrates the complete Business Intelligence workflow:

- Import CSV data into MySQL
- Connect MySQL with Power BI
- Clean and transform data using Power Query
- Create DAX calculated columns and measures
- Build interactive dashboards
- Generate business insights

---

## 🛠️ Tech Stack

- Power BI
- MySQL
- Power Query
- DAX
- Microsoft Excel (CSV)

---

## 📂 Project Workflow

1. Prepare CSV Files
2. Create Tables in MySQL
3. Import CSV Files into MySQL
4. Connect MySQL to Power BI
5. Transform and Clean Data in Power Query
6. Create DAX Measures and Build Interactive Dashboards

## 📈 Key Insights

### Weekly Performance

- Revenue increased by **28.8%** (Week-over-Week)
- Total Transaction Amount increased by **47.1%**
- Total Transaction Count increased by **3.4%**

### Overall Dashboard Insights

- Overall Revenue: **57M**
- Total Interest Earned: **8M**
- Total Transaction Amount: **46M**
- Customer Income: **588M**
- Customer Satisfaction Score (CSS): **3.19**
- Blue Card category generated the highest revenue.
- Swipe transactions generated the highest transaction volume.
- Graduate customers contributed the highest revenue.
- Businessman customers generated the highest revenue.
- Male customers generated higher revenue than female customers.
